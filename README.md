# 2D RPG · Rpg2D

Unity **2022.3.62f3c1** · Built-in 渲染管线

用 Unity 打开 `Rpg2D/`，运行 `Assets/Scenes/MainMenuScene.unity`。

## 操作

| 移动 | WASD / 方向键 |
|---|---|
| 跳跃 | 空格 |
| 攻击 | 鼠标左键 |
| 翻滚 | F |
| 格挡 | 鼠标右键 |
| 魔法球 | G |

## 目录

- `Assets/Scripts/Framework` — 资源/场景加载、协程、对象池、UI 基类
- `Assets/Scripts/Managers` — 单例管理器
- `Assets/Scripts/Entities` — 实体、状态机、属性
- `Assets/Scripts/UI` — 界面
- `Assets/Data` — ScriptableObject 数据
- `Assets/Prefabs` — 预制体
- `Assets/Resources` — UIRoot、GameResources、I2 语言表

## 依赖

Cinemachine · TextMeshPro · 2D Feature Set · I2 Localization · LitJson
